# 💧 地下水位升降與颱風降雨分析工具 (Groundwater & Rainfall Analysis Tool)

## 📖 專案簡介
本專案為一個基於 **Python + Streamlit** 開發的互動式資料視覺化與水文分析 Web 應用程式。
主要目的為協助水利工程師、研究人員或防災人員，透過上傳歷史觀測數據 (CSV / Excel)，快速分析**特定降雨事件（如颱風、豪雨）期間，降雨量與地下水位抬升/洩降的關聯性**。

---

## 🚀 核心功能 (Core Features)

1. **多格式彈性資料載入 (CSV & Excel Support)**
   - 支援 CSV（具多種中文編碼自動降級重試）與 Excel（`.xlsx`, `.xls`）格式。
   - **智慧全域掃描器**：自動掃描 Excel 檔案中的日期時間欄位，並自動避開前方的測站說明與中文雜訊列。
   - **手動彈性欄位對應**：上傳檔案後可透過側邊欄下拉選單自由指定「時間欄位」與「數值欄位」。
   - **雨量欄位按需勾選**：預設維持不全選，讓使用者依需求自行勾選欲分析的雨量欄位，維持介面整潔。

2. **智慧雨量類型辨識與速率換算**
   - **自動辨識**：自動識別特殊代號（如 `R1` 為日雨量）或透過名稱中的關鍵字（如 `1小時`、`3小時`、`24h`）辨識計量時段。
   - **動態水位變率換算**：根據區間內的水位變化總量（`m/day`），對應選定的雨量時段自動換算為相應的水位升降速率（例如 `m/1小時`、`m/日`）。

3. **互動式雙軸時間序列圖 (Interactive Dual-Axis Time Series)**
   - 採用 `Plotly` (`make_subplots`) 繪製。
   - **上層（折線圖）**：地下水位歷線。
   - **下層（群組長條圖）**：支援多欄位（多時段）雨量同步顯示。
   - **自訂事件標註**：透過表格自由新增颱風名稱與日期，圖表自動繪製紅色虛線與數值標籤（包含當下精準的水位與雨量對應值）。

4. **降雨與水位相關性對數迴歸分析 (Logarithmic Regression Analysis)**
   - 將時間序列重取樣（Resample）為「每日極值」進行配對。
   - **有效降雨門檻（Threshold）**：過濾日常微弱降雨雜訊，專注分析突出事件。
   - **數學模型**：利用對數迴歸方程式 $y = a \cdot \ln(x) + b$ 擬合趨勢，並計算決定係數 $R^2$。
   - **視覺亮點**：使用者自訂的颱風事件會以「紅色大星星」獨立標記於散佈圖中。
